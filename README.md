# TACTICAL XI — The Manager's Mind

전술 중심 축구 감독 커리어 게임의 **실행 가능한 초기 프로토타입(v0.1)**입니다. UI와 코드가 한국어 사용자에게 맞게 작성되었습니다.

## 실행

`index.html`을 브라우저에서 열거나, 전체 폴더를 GitHub 저장소에 올린 뒤 GitHub Pages에서 실행합니다. 별도 라이브러리 또는 서버 없이 작동합니다. 스마트폰 세로 화면에 대응합니다.

## 이미 구현된 기능

- 공 소유/미소유 시 포메이션 **별도 지정**; 전술판의 11명을 손가락이나 마우스로 이동
- 공격·수비·전환·특수 지시 등 **40개 이상**의 개별 팀 전술 옵션
- 모든 선수의 공 소유/미소유 역할과 **12개 개인 행동 지시**
- 상대 포지션별 압박·마킹·태클·유도할 발 지정
- 코너킥, 프리킥, 스로인, 수비 세트피스 지시
- A/B/C 전술 3개 저장 및 경기 중 교체
- 매치데이 5/15분 단위 전개. 언제든 전술실 이동해 설정 변경 후 경기 재개
- 상대 감독의 경기 중 전술 변경, 상황별 이벤트, xG·슈팅·점유율 추정
- 간략 커리어: 시즌, 경기 기록, 명성, 신임도, 성적 부진 시 경질
- 브라우저 localStorage 자동 저장 및 모바일 레이아웃

## 중요한 한계

이 파일은 **FM급 경기 엔진이 아닙니다**. 실제 선수 22명이 물리적으로 이동하는 시뮬레이션 대신, 전술 설정을 **확률 기반 전술 경기 모델**로 계산하는 프로토타입입니다. 옵션 중 일부의 효과는 기본 모델에서 종합 지표로 반영되며, 모든 개별 옵션이 독립적인 위치 움직임이나 패스 애니메이션으로 구현된 것은 아닙니다. 이는 후속 단계에서 개선해야 합니다.

다음 구현 우선순위: 지역별 공간 점유 계산, 선수별 이동/패스/압박 상태 머신, 상대 감독의 실제 전술 보드 변화, 경기 분석 보고서, 감독 커리어 이직·리그 추가.

## 파일 구성
- `index.html`: 게임 뼈대 및 화면
- `style.css`: 모바일 포함 UI 디자인
- `data.js`: 포메이션, 팀, 전술 정의
- `engine.js`: 전술 점수 계산, 경기 시뮬레이션, 감독 커리어 진행
- `app.js`: 전술 편집/드래그/자동저장/경기 화면 연결
