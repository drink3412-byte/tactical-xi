# TACTICAL XI v0.3 — 전술로 승부하는 축구 감독 시뮬레이션

## 플레이
GitHub Pages에서 `index.html`을 실행합니다. 별도 서버나 로그인은 필요하지 않습니다.

## v0.3: 터치라인 전술 분석관
- 경기 전·중 **위험 경로 2개**를 상대의 전술과 나의 설정 수치로 추정합니다.
- 상대가 공격 기회를 만들면 가능한 공격 경로와 슈팅 xG를 매치 로그에 기록합니다.
- 위험 신호나 실점이 발생하면 `15분 진행` 중이라도 자동으로 중단해 **전술 수정 시간**을 줍니다.
- 실점 경로, 당시 지시 수치, 점검할 방향을 알려주고 관련 전술 설정으로 바로 이동시킵니다. 자동 수정이나 4지선다 선택지는 없습니다.
- 이전 실점의 원인 기록과 상대 감독 전술 변경을 확인할 수 있습니다.
- 공격/수비/전환/빌드업/체력 및 세트피스 위험도를 현재 설정에 연동합니다.
- **주의**: 22명 선수의 물리적 움직임을 추적하는 엔진은 아닙니다. 경로와 위험은 전술 확률 모델의 추정값입니다.

## 기존 기능
- 공 소유와 공 미소유 포메이션을 개별 배치하고 선수 위치를 드래그합니다.
- 포지션별로 올바른 개인 역할만 선택할 수 있습니다.
- 윙어는 정통 윙어, 볼 운반형 윙어, 인사이드 포워드, 인버티드 윙어 등을 지정합니다.
- 팀/개인/상대 선수별/세트피스 전술 설정, A/B/C 슬롯, 오프라인 저장 및 감독 커리어.

## 파일 구조
- `index.html`: UI 구조
- `style.css`: 반응형 디자인
- `data.js`: 포지션/역할/전술 정의
- `engine.js`: 경기 확률 및 진단 엔진
- `app.js`: UI/저장/상호작용

## 배포
저장소 **Settings → Pages → Deploy from a branch → main / (root)**.
