# TACTICAL XI — The Manager's Mind

전술을 직접 설계하고 상대 감독의 대응에 맞서 싸우는 브라우저 기반 감독 커리어 게임입니다. 선수 영입, 계약, 훈련을 생략하고 전술 설정과 경기 분석에 집중합니다.

## v0.2 — Position-locked Role Studio

- 드래그한 **실제 전술판 위치**에 따라 GK / CB / LB·RB / WB / DM / CM / AM / LW·RW / LM·RM / ST를 분류합니다.
- 공 소유 역할과 공 미소유 역할은 별도로 선택할 수 있으며, 해당 위치에서 가능한 역할만 선택할 수 있습니다. 스위퍼 키퍼는 GK만 사용할 수 있습니다.
- 역할을 바꾸면 해당 역할의 기본 행동 지시가 적용되고, 아래 슬라이더에서 다시 직접 수정할 수 있습니다.
- 특히 윙어는 **정통 윙어, 볼 운반형 윙어, 인버티드 윙어, 인사이드 포워드, 와이드 플레이메이커, 크로스 특화 윙어, 압박형 윙어** 등을 구분합니다.
- 볼 운반, 1:1 돌파, 안쪽 침투, 슈팅, 얼리 크로스, 스루패스, 뒷공간 침투 등 지시가 경기의 공격 지표와 기록에 반영됩니다.
- 기존 v0.1의 브라우저 저장 데이터는 자동으로 새 포지션 제약을 따르도록 변환합니다.
- 포지션 안내 태그, 역할 설명 카드, 개인 지시 편집 화면을 모바일에서도 사용할 수 있게 개편했습니다.

## 실행

GitHub Pages로 배포하거나, 파일을 모두 동일 폴더에 저장한 다음 `index.html`을 브라우저에서 열면 됩니다. 추가 서버/빌드 단계가 필요 없습니다.

## 조작

1. **전술실**에서 공 소유 / 공 미소유 모드를 선택합니다.
2. 경기장 선수 마커를 드래그하면 포지션이 바뀌고 역할 범위도 즉시 변경됩니다.
3. **개인 역할** 탭에서 선수 번호를 누르고 가능한 역할을 선택합니다.
4. 역할 카드를 선택한 뒤 세부 슬라이더를 이용해 원하는 행동을 직접 지시할 수 있습니다.
5. **매치데이**에서 경기를 진행하고, 언제든 전술실로 돌아가 다시 수정할 수 있습니다.

## 현재 한계

현재 경기는 22명의 물리적 움직임이 아니라 역할과 팀 전술을 확률 모델에 반영한 초기 시뮬레이션입니다. 전술의 실제 장면별 움직임과 상대 선수 AI는 이후 단계에서 발전시켜야 합니다.

## 파일

- `index.html`: 페이지 구조
- `style.css`: UI 스타일
- `data.js`: 포메이션, 포지션 판별, 역할 데이터 및 기본 프리셋
- `engine.js`: 경기 시뮬레이션 모델
- `app.js`: 전술 편집 UI, 이벤트, 저장, 경기 진행, 커리어 로직
